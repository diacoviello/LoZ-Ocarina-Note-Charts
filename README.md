# LoZ Ocarina Note Charts

Note and fingering charts for the ocarina in *The Legend of Zelda: Ocarina of Time* on Nintendo Switch 2.

The ocarina has five note buttons (L, R, A, Y, X). The D-pad bends a note by a half step and the left stick bends it by a whole step, and you can combine the two. That gives **19 pitches from 45 inputs, across the range B3–F5**. These charts show every way to play each pitch, plus practical fingerings for playing all 12 major scales in tempo.

## Quick reference

| Button | L | R | A | Y | X |
|---|:-:|:-:|:-:|:-:|:-:|
| Pitch | D4 | F4 | A4 | B4 | D5 |

| Semitones | Hold with the note button |
|:-:|---|
| +3 | D-pad ↑ + Stick ↑ (claw grip) |
| +2 | Stick ↑ |
| +1 | D-pad ↑ |
| −1 | D-pad ↓ |
| −2 | Stick ↓ |
| −3 | D-pad ↓ + Stick ↓ (claw grip) |

Hold the modifier first, then press the note button, so the note starts on pitch. Bends only work in free play. The game recognizes songs from the five natural notes only.

## Notes on pitch names

Pitch names follow the original game's layout (L = D4 through X = D5). Nintendo hasn't published the remake's sounding octave, so read the octave numbers as written pitch.
